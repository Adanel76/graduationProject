# Тестирование проекта Travel Agency

В проект добавлено покрытие основных сценариев backend и frontend.

## Backend

Перед первым запуском:

```powershell
cd backend
pip install -r requirements.txt
```

Запуск:

```powershell
pytest
```

Покрытые зоны:

- авторизация и подтверждение email;
- загрузка, проверка и удаление аватарки;
- проверка онлайн-пользователей;
- права доступа клиента, менеджера, аналитика и администратора;
- бронирования и смена статусов;
- уведомления;
- избранное;
- отчёты CSV;
- создание и фильтрация туров;
- экспорт туров в CSV;
- импорт туров из CSV;
- CSV-центр аналитика;
- аналитическая панель;
- MetricBot / ML-сводка.

## Frontend

Запуск:

```powershell
npm run test:frontend
```

Покрытые зоны:

- helper-функции API для изображений туров;
- карточка тура: отображение цены, рейтинга, мест, избранного и перехода в детальную страницу;
- BI-блок аналитики: проверка структуры “Краткая сводка модели → Оперативная картина / Контроль данных”;
- базовая проверка главного React-компонента.

## Полный запуск

```powershell
npm run test:all
```
